## 🛠️ Getting Started in 3 Simple Steps

Connecting EasySendSMS to your WordPress site takes less than 5 minutes. 

### Step 1: Create Your Free EasySendSMS Account
Register at **[EasySendSMS](https://my.easysendsms.app/register)** to get your API credentials. You will receive **15 free SMS credits** instantly to test your setup.

### Step 2: Install the WSMS Plugin
Navigate to your WordPress dashboard, go to **Plugins > Add New**, search for **WSMS** (or WP-SMS), and install the plugin. 

### Step 3: Configure the EasySendSMS Gateway
1. Go to the **WSMS Settings** in your WordPress menu.
2. Navigate to the **Gateways** tab.
3. Search for **EasySendSMS** and select it.
4. Enter your EasySendSMS `Username` and `Password`.
5. Save changes and send a test message!

> 📚 Need detailed setup instructions? Check out the official **[WSMS Documentation](https://wsms.io/docs/)** or visit the **[EasySendSMS Gateway Page](https://wsms.io/gateways/easysendsms/)**.
